## 💫 About Me

🔭 I'm currently working on a **10G Ethernet MAC** design in Verilog, plus **UVM-based verification** for a sync FIFO and an APB slave
<br/>
👯 I'm looking to collaborate on RTL design and verification projects: UVM environments, protocol IPs (APB, Ethernet), and CRC/datapath modules
<br/>
🤝 I'm looking for help with scaling my UVM work to larger, multi-agent environments and reviewing my testbench architecture
<br/>
🌱 I'm currently learning advanced UVM (RAL, virtual sequences, scoreboard design) and protocol-level verification for ASIC/FPGA roles
<br/>
💬 Ask me about Verilog, SystemVerilog, SVA, functional coverage, CRC implementations, or Questa Sim / EDA Playground workflows
<br/>
⚡ Fun fact: I'd rather debug a waveform in Questa than a bug in my own head
